# 语义搜索解决方案架构设计

## 1. 架构概述

本解决方案基于华为云构建企业级语义搜索系统，支持：
- 传统关键词搜索（BM25）
- 向量语义搜索
- RAG（检索增强生成）
- 对话式搜索

## 3. 核心组件

### 3.1 APIG（API 网关）
- 统一入口，暴露 RESTful API
- 请求认证与限流
- 日志记录与监控

### 3.2 CCE（云容器引擎）
- 容器化后端服务部署
- 支持 Kubernetes 编排
- 自动伸缩，高可用

### 3.3 后端服务（容器）
- 搜索API处理
- 文档索引构建
- RAG 对话处理
- 向量化处理

### 3.4 CSS（云搜索服务）
- 向量索引存储
- 全文索引
- 混合搜索（BM25 + 向量）

### 3.5 ModelArts
- 文本向量化模型部署
- embedding 服务

### 3.6 盘古/MaaS
- 大语言模型
- RAG 答案生成

## 4. 数据流设计

### 4.1 索引构建流程
```
文档 → 文本预处理 → 分词 → 向量化 → CSS 向量索引
```

### 4.2 搜索流程
```
用户查询 → APIG → CCE容器 → 向量化 → CSS 向量搜索 → 返回结果
```

### 4.3 RAG 对话流程
```
用户问题 → APIG → CCE容器 → 向量化 → CSS 检索 → 构建 Prompt → 盘古/MaaS → 生成答案
```

## 5. 安全设计

### 5.1 访问控制
- IAM 细粒度权限控制
- APIG API 密钥认证
- 容器安全组配置

### 5.2 数据安全
- HTTPS 传输加密
- CSS 数据加密存储
- 敏感信息环境变量管理

## 6. 扩展性设计

- **计算扩展**：CCE 容器自动伸缩，灵活应对流量变化
- **存储扩展**：CSS 支持集群扩展
- **模型扩展**：可替换 embedding 模型和大模型
